# Security policy

This project is a deterministic receipt verifier. It does not scan third-party repositories, servers, or endpoints.

Only submit artifacts and receipts that you own or are explicitly authorized to test. A receipt is evidence about a stated artifact, scope, scanner, and time window; it is not a global security guarantee.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow from the repository
Security tab when it is available. If that flow is unavailable, contact the
repository owner privately through the GitHub profile for `Xander-Xai`.
Do not open a public issue for an unpatched vulnerability.
